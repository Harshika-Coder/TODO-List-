# TODO-List
A simple and interactive TO-DO List application built using HTML, CSS, and JavaScript. This project helps users organize tasks efficiently with an intuitive interface and responsive design.
🚀 Features
- ➕ Add new tasks easily
- ✅ Mark tasks as completed
- 🗑️ Delete tasks instantly
- 🎨 Clean and responsive UI with modern styling
- 💾 Local storage support (tasks remain saved even after refreshing the page)

🛠️ Technologies Used
- HTML5 – Structure of the app
- CSS3 – Styling and layout (Flexbox, transitions)
- JavaScript (ES6) – Functionality and DOM manipulation
